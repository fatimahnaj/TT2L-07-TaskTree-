# Project Title : TaskTree

## Description :
A fun mini game project where user can grow flowers by collecting money from using the pomodoro timer. Fully grown flowers can later be plant in the forest for showcase.

## Features : 
- Pomodoro timer
- to do list
- shop (to buy seeds and materials to grow flowers)
- built in chill lofi music
- growing flowers

## Tech details :
Languages : python , pygame
